# E-Commerce Application

A full-stack E-Commerce application built using **FastAPI**, **React.js**, **Vite**, and **PostgreSQL**.

The application provides user authentication, product management, shopping cart functionality, and order management through REST APIs.

---

## Tech Stack

### Backend
- Python
- FastAPI
- SQLAlchemy
- PostgreSQL
- JWT Authentication
- Uvicorn

### Frontend
- React.js
- Vite
- JavaScript
- HTML
- CSS

### Database
- PostgreSQL
- Neon PostgreSQL for deployment
