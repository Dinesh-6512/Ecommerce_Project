# UI & UX Document
## E-Commerce Application

### Customer Screens

#### 1. Home
- **What the user sees:** A welcome banner, a search bar, and a grid of featured products.
- **What the user can do:** Search for a product, click on a featured product, or navigate using the top menu (Login/Register/Cart).
- **Where the user goes next:** Product Listing, Product Details, Login, or Register.

#### 2. Product Listing
- **What the user sees:** A list or grid of products, showing an image, title, and price for each. A sidebar to filter by category.
- **What the user can do:** Scroll through products, filter by category, or click on a specific product.
- **Where the user goes next:** Product Details.

#### 3. Product Details
- **What the user sees:** A large product image, description, price, and an "Add to Cart" button.
- **What the user can do:** Read about the product, select a quantity, and click "Add to Cart".
- **Where the user goes next:** Cart (after adding), or back to Product Listing.

#### 4. Cart
- **What the user sees:** A list of added products with their quantities, individual prices, and the total order price. A "Checkout" button.
- **What the user can do:** Change product quantities, remove a product, or proceed to checkout.
- **Where the user goes next:** Checkout, or back to browsing.

#### 5. Checkout
- **What the user sees:** A summary of their order, a form to enter shipping details, and a fake payment button ("Place Order").
- **What the user can do:** Fill out their shipping address and confirm their order.
- **Where the user goes next:** Order Confirmation.

#### 6. Order Confirmation
- **What the user sees:** A success message and an order number.
- **What the user can do:** Read the confirmation.
- **Where the user goes next:** Home or Order History.

#### 7. Order History
- **What the user sees:** A list of past orders with dates, total amounts, and their current status (e.g., pending, shipped).
- **What the user can do:** Review their past purchases.
- **Where the user goes next:** Home or Profile.

#### 8. Login
- **What the user sees:** Email and password input fields, and a "Login" button.
- **What the user can do:** Enter their credentials to access their account.
- **Where the user goes next:** Home or Register (if they don't have an account).

#### 9. Register
- **What the user sees:** Input fields for Name, Email, Password, and a "Sign Up" button.
- **What the user can do:** Create a new account.
- **Where the user goes next:** Login.

#### 10. Profile
- **What the user sees:** Their name and email address. A link to their Order History.
- **What the user can do:** View basic account info or logout.
- **Where the user goes next:** Home or Login (if logged out).

### Admin Screens

#### 1. Admin Login
- **What the user sees:** Email and password input fields for admins only.
- **What the user can do:** Log into the admin portal.
- **Where the user goes next:** Admin Dashboard.

#### 2. Admin Dashboard
- **What the user sees:** A welcome message and quick links to manage products, categories, or orders.
- **What the user can do:** Choose which section to manage.
- **Where the user goes next:** Product Management, Category Management, or Order Management.

#### 3. Product Management
- **What the user sees:** A list of all products in the store and a button to "Add New Product".
- **What the user can do:** View the list, click to edit a product, delete a product, or add a new one.
- **Where the user goes next:** A form to edit or create a product.

#### 4. Category Management
- **What the user sees:** A list of product categories and a button to "Add New Category".
- **What the user can do:** Add a new category name, or edit/delete existing ones.
- **Where the user goes next:** Admin Dashboard or Product Management.

#### 5. Order Management
- **What the user sees:** A list of all customer orders, showing the customer name, order date, and current status.
- **What the user can do:** Click an order to see its details and change the status (e.g., from "pending" to "shipped").
- **Where the user goes next:** Admin Dashboard.
